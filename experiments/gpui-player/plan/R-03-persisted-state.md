# R-03: persisted state

Electron profile identity: desktop sets the app name `SingZ` and product profile directory `SingZ`; Box sets `SingZ Box` and profile directory `SingZ Box` (`src/shared/product-identity.ts:11-25`). Box explicitly sets `userData` to `<appData>/SingZ Box`; desktop uses Electron's default `userData` derived from its app identity, unless `SINGZ_USERDATA_DIR` overrides it (`src/main/bootstrap.ts:21-38`). Thus native default locations below are distinct from Electron profiles. *(inferred)* Exact Electron platform-specific resolved paths are not constructed in repository code; Electron supplies `appData` / `userData` (`src/main/bootstrap.ts:30-38`).

Short notes:

- Desktop and Box have separate Electron profile identities; do not assume their settings, caches, or renderer storage are interchangeable (`src/shared/product-identity.ts:11-25`; `src/main/models.ts:17-23`).
- Electron renderer `localStorage` is profile/origin storage, not a file key exposed by the supplied code; native must map user-facing values rather than copy its browser database. *(inferred)*
- Native `TokenStore` explicitly documents that it does not read Electron settings (`experiments/gpui-player/src/drive_auth.rs:236-239`).
- Exact Electron resolved profile paths and native model default roots could not be determined from the requested source set: Electron delegates path resolution to Electron, while the native model module receives configured roots. *(inferred)*
