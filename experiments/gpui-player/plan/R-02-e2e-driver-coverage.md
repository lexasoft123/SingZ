### Five-line summary

The actual roster is 27 drivers: 22 macOS, two Windows, and three capture-addon; three extra macOS files are helpers.
Native coverage is strongest for transport/audio, count-in, lyrics, training and graph checks, but cross-screen workflows remain separate.
Visible Windows CPU sampling has no native counterpart in the inspected native checks.
Windows CI smoke does not exercise Play; the verifier assigns real Windows playback to the field-laptop `player-session-e2e.cjs` run (`.claude/agents/e2e-verifier.md:26`, `:41`).
