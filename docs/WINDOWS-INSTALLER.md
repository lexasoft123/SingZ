# Native Windows installer

On Windows 10/11, use Python 3, NSIS **3.10 or newer** (Unicode `makensis.exe` on PATH), and the already-built release runtime, lyric engines, and pinned singz-ui font notices described in the native desktop packaging runbook. The compiler and all inputs must be available to the limited build user; no administrator rights are required by the installer. From the repository root in PowerShell, with fresh output paths:

```powershell
python scripts/package-gpui-desktop.py --platform windows --runtime-dir experiments/gpui-player/target/release --engines-dir path/to/engines --uikit-dir path/to/singz-ui --output-dir build/singz-native-payload --installer build/singz-native-setup.exe
```

Create the parent output directory first. The payload includes both engines, and the installer includes the complete manifest inventory. It installs for the current user into `%LOCALAPPDATA%\Programs\SingZ Native`, adds distinct Start menu and desktop shortcuts and an HKCU uninstall entry, and supports NSIS `/S` for silent install and uninstall. Uninstall deletes the installed inventory and shortcuts; it does not remove settings, models, packs or projects. Files added separately inside the install directory are left in place.

Without a certificate the packager warns, records `unsigned` in the payload manifest, and triggers a Windows SmartScreen prompt on first install. For signed builds install Windows SDK SignTool and make it available on PATH (or set `SINGZ_SIGNTOOL` to its path), and set `SINGZ_SIGN_TIMESTAMP_URL` to an RFC 3161 timestamp service. Select a certificate either with `SINGZ_SIGN_THUMBPRINT` (SHA-1 thumbprint from the current user's certificate store) or with both `SINGZ_SIGN_PFX` and `SINGZ_SIGN_PASSWORD_FILE` (UTF-8 password file, without trailing newline). Do not set both selection methods. The password is never printed, though SignTool receives it as a process argument; restrict access to the build account and host. DLLs, engines, helpers and the player are signed before the manifest is calculated; NSIS signs the uninstaller at compile time and SignTool signs the final installer. Signing failures stop the build. Set `SINGZ_MAKENSIS` if makensis is not on PATH.

The wizard uses NSIS built-in translations for all shipped locales except Filipino, which NSIS does not provide; Windows chooses the matching system UI language automatically and falls back to English when no match is available. The Windows 11 VM and Windows 10 field laptop must still qualify interactive and silent install, launch and uninstall as a limited user with a non-ASCII profile, and confirm the shared library, models, packs, native settings and Electron install remain intact. Signed artifacts additionally need `signtool verify /pa` for every executable, DLL and installer/uninstaller.
