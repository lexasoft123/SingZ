The band can wait. Your next note cannot.

### Desktop

- **Keep training with a song open.** Reference notes play through the shared native audio output. Back returns to the training page instead of the song.
- **Finish the note on screen, too.** The progress bar fills before the next note appears. Paused practice and result feedback use the app’s shared controls and centered banner style.
- **Spend less time preparing.** Audio devices are cached and refreshed on reconfiguration; the microphone and analysis runtime reuse their prepared resources between exercises. Native cue and microphone timestamps now use the same clock.
- **Export without guessing.** Clearer export mode and format controls, with MP3 selected by default.

### Desktop, iPhone and Android

- **Hear the instruments more clearly.** Reference notes gain 5.5 dB without compression, preserving the current attack and sustain. Whole-phrase gain is capped at available peak headroom when you raise the volume.
- **One native audio output for songs and training.** Reference playback shares the native host rather than opening another live output. Microphone analysis continues through the existing native detector; this does not move every training stage into zcore.

### Android

- **Keep listening after the reference note.** Starting or replaying a cue no longer makes SingZ interrupt its own microphone session. Real audio interruptions still stop the session safely.

### По-русски

На компьютере эталонные ноты звучат и при открытой песне, а «Назад» возвращает к тренировкам. Шкала доходит до конца перед следующей нотой; сообщения выровнены по центру и используют общий компонент интерфейса. Подготовка микрофона стала быстрее. В экспорте понятнее выбор режима и формата, MP3 выбран по умолчанию.

На компьютере и телефонах эталонные инструменты звучат на 5,5 дБ громче без компрессии, сохраняя естественный характер. При высокой громкости усиление всей фразы ограничивается запасом до перегрузки. Тренировки и песни используют общий нативный аудиовыход.

На Android запуск или повтор эталонной ноты больше не прерывает микрофон тренировки.

Songs and project files remain compatible with earlier versions. Store availability follows each platform’s publication workflow.
