v0.14.1-test12 — Test build: the pack goes on a diet

The GPU result stands (a song in 2.4 seconds on the 4060 Ti) — this build
makes the download worthy of it. The pack was carrying the model twice, two
copies of the AI runtime, 40 MB of debug symbols and a GUI toolkit nothing
uses. Now it ships one model (the fast graph, half-size weights — the same
trick the original download used, verified bit-close), one runtime, and no
dead weight: roughly 340 MB instead of 525.

To test it: install, let it download the slimmer pack, GPU in the model
manager, split a new song and then a second one (the second should start
with no warm-up at all). The processor-only path uses the same faster model
now too, so even CPU machines get a little quicker. Log as always.
