v0.14.1-test8 — Test build: the GPU gets a model it can actually chew

test6 made history — the first GPU split this project has ever completed —
and then lost the race to its own CPU. We found out why: the model file, as
exported, is one part music math to sixty parts bookkeeping, and the new
engine kept handing the bookkeeping back to the CPU, paying a toll at every
border crossing. This build ships a second copy of the model with all the
bookkeeping done in advance (18x fewer pieces, bit-identical output,
verified at build time) that only the GPU engine uses — plus a compile
cache, so the ~30-second warm-up happens once ever instead of every song.
(test7 was this same build; its factory ran out of memory doing the
bookkeeping-folding on the spot, so now the folded model is baked ahead
of time and the factory just checks its fingerprint.)

To test it: install, let it download the updated pack (~530 MB — the
pre-chewed model rides along), GPU in the model manager, split a new song,
send the log. The second song you split tells us as much as the first — the
warm-up should be gone.
