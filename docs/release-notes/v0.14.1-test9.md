v0.14.1-test9 — Test build: asking the graphics card how it feels

test8 proved the model now reaches the GPU in one piece — and it still runs
at a fraction of what the card can do, slower than the CPU sitting next to
it. The math says the card is loafing at around a thousandth of its
ability, which usually means power management, not our code: an unplugged
laptop, a quiet-fan mode, or a card parked at idle clocks. This build asks
the driver directly — while a song splits, the log now records the card's
utilization, clock speed, power draw and temperature every fifteen seconds.
(The engine-build chatter from test8 is muted; it wrote a small novel into
the log.)

To test it: install (no new pack — test8's is current), plug the laptop in,
set Windows power mode to Best performance if it isn't, GPU in the model
manager, split a new song, send the log. The telemetry lines will name the
culprit either way.
