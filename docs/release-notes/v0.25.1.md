Your phone deserves another verse before being sent to the computer.

- **Split stays within reach.** A failed attempt keeps its Split button and actual error. Retry can resume a checkpoint; repeated failures no longer replace the cause with advice to use a computer.
- **Android splitting uses less memory.** It now shares the conservative session settings already used on iPhone. The six-stem model and output format are unchanged. Splitting may take a little longer, and a phone under memory pressure can still stop the job.
- **The first Android tap gets a second delivery when needed.** If the system accepts the request but never delivers it to the split service, SingZ retries that delivery once. It does not create a second worker.
- **Cancel means cancel, even before the split starts.** Cancelling during preparation no longer leaves a late start request behind. Starting another song waits for cleanup, so the previous job cannot clear the new one.
- **An interrupted iPhone job becomes retryable after restart.** A worker still held by the current app session explains the restart it needs and preserves the checkpoint.
- **Downloaded Drive songs stay ready.** Background refresh no longer makes an already downloaded song wait for Drive. Your local copy remains usable offline, and removing it updates the library immediately.

The split runtime is updated across supported phone and desktop targets. Songs and stem files remain compatible with earlier projects.
