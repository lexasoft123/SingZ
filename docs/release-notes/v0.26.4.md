v0.26.4 — Windows microphone fix

<!-- store:en-US -->
Windows microphones can start again, including USB audio interfaces such as MiniFuse. Saved microphone and input-channel selections are preserved. If capture fails, the app log now includes the underlying error to help diagnose the connection.

Fixes a Windows microphone startup regression introduced by the shared audio device inventory. Both current and older saved device identifiers are accepted. Native capture failures are recorded in the existing app log.

Reported in #116 with Windows 11 and an Arturia MiniFuse 2. Hardware confirmation from the reporter is pending.
