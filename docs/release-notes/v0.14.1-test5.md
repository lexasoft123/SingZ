v0.14.1-test5 — Test build: the new GPU engine answers to its real name

test4 shipped the new TensorRT RTX engine — and then didn't recognize your
RTX 3060, because the engine introduces itself under a different name than
its documentation claims (we read the real one out of the library itself).
This build matches the name loosely and prints every engine it sees into the
log, so a surprise like this can never hide again.

To test it: install (no new pack download this time — test4's pack is
current), switch to GPU in the model manager, split a new song, send the
log. The first GPU song compiles the model for your card; after that it
should be quick.

Everyone else: nothing to see here, as usual for test builds.
