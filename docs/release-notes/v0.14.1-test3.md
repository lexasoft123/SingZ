v0.14.1-test3 — Test build: small-bites GPU mode, actually switched on

test2 had a wiring bug on our side: the "smaller bites" GPU retry announced
itself in the plan but the switch never reached the engine, so the second
attempt just repeated the first. This build actually flips it — the log will
say "DirectML graph fusion off — submitting the model in small pieces" on
the retry — and a test now pins that wiring so it cannot silently regress.

To test it: same dance as before — install, model manager, switch to GPU,
split a new song, save the log and send it. If the small-bites retry
survives, the seconds-per-chunk number is the one that decides whether GPU
splitting is worth keeping on this road or we take the other one.

Everyone else: nothing to see here — single-GPU machines and the regular
update channel are untouched.
