v0.14.1-test10 — Test build: naming the layer that eats 98% of the card

test9's telemetry acquitted the power management: your card runs flat out —
full utilization, ninety-five watts — and still loses to the CPU. So the
waste is inside specific layers of the model, and this build makes the
engine time every one of them. After a song finishes splitting, the log
prints a leaderboard of where the GPU seconds actually went.

To test it: install (no new pack), GPU in the model manager, split one new
song, send the log. The lines that start with "gpu profile:" at the end of
the split are the whole point — they name the guilty layer, and with a name
we can either work around it or file a precise bug with NVIDIA.
