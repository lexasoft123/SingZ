v0.26.7 — The encore is back on

The repeat button has one job. It should not need a maths degree to do it.

### Desktop

- **Whole-song loops start singing again.** Some songs refused to play with repeat enabled because their end landed between two audio frames. Playback now agrees on where the song ends, so that tiny rounding difference cannot stop the entire performance.
- **A warmer welcome on Mac.** The installer has a new dark-and-gold look, with a clear arrow to Applications. Same drag, better stage lighting.

### iPhone, iPad and Android

- **Downloads you can follow.** Song downloads show bytes transferred and transfer speed, with progress that reflects file sizes rather than treating a tiny file like a giant stem.
- **A bad connection gets another chance.** Temporary download failures retry automatically. Stalled transfers time out, and you can cancel a song load instead of waiting indefinitely. Completed cached files can be reused on the next attempt.
- **A little more elbow room.** Compact Settings and Log icons keep the library and training headers tidy.
