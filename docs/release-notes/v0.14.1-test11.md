v0.14.1-test11 — Test build: the two layers that ate the graphics card

test10's stopwatch found them: of 315 GPU-seconds per song, 310 went to the
two layers that turn the spectrogram back into sound — and the other 604
layers, the entire neural network, ran in a tenth of a second per chunk.
Those two layers were written in a form NVIDIA's engine handles terribly;
mathematically they're a simple matrix multiply plus overlapping sums, so we
rewrote them exactly that way (bit-identical output, verified). This build
downloads an updated pack with the rewritten model. The stopwatch is off
again, which also brings back the engine cache the stopwatch was breaking.

To test it: install, let it download the pack (~530 MB), GPU in the model
manager, split a new song — and then a second one. If the math is right,
the split should take seconds, not minutes, and the second song should
start without any warm-up. Log as always; the telemetry lines stay in.
