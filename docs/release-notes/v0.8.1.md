v0.8.1 — the polish pass

**The polish pass.**

- **The word halo grew up.** The traveling amber glow on the word being sung used to end in a hard-edged box on phones (a quirk of how iOS clips text shadows). It now fades out like light should.
- **Your Drive library stopped pretending to load.** Coming back from a song shows the catalog instantly, from cache, with zero network — and the first listing of a session runs five folders at a time with a real progress spinner instead of a dead screen. Songs were always cached after first play; now the *list* is too.
- **The desktop finally explains its clouds.** One storage panel, two plain sentences: "Your library lives here · syncs via iCloud" on top, "A copy also lives in your Google Drive · up to date" beneath — with live progress while it copies. No more guessing which cloud is which.
- The screen stays awake on phones, the first line of every song counts you in, and Android release builds got a compiler cache (you don't care, but future releases arrive faster).

Android: sideload `SingZ-v0.8.1-android.apk` below. Mac and Windows update themselves, as they should.
