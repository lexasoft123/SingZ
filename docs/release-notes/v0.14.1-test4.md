v0.14.1-test4 — Test build: a new GPU engine entirely (TensorRT RTX)

The verdict from the last three builds: the old GPU engine (DirectML) cannot
run this model on any graphics card we have seen — the driver either times
out or runs out of memory, and Microsoft has stopped developing it. So this
build brings a different engine: NVIDIA's TensorRT RTX, made exactly for
GeForce RTX 30xx-and-newer cards. The splitter now tries it first, then the
old engine, then CPU — and this build downloads a bigger splitter pack
(~440 MB, up from ~280) that carries the new engine inside.

To test it: install, let it download the updated splitter pack when it asks
(the old one is now too old for this build), make sure GPU is picked in the
model manager, split a new song, and send the log. The first GPU song
compiles the model on your card ("seconds", says NVIDIA — the log will
tell); after that it should be fast every time.

Everyone else: nothing to see here — the regular update channel and every
non-test machine are untouched.
