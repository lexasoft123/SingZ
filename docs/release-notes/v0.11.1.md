v0.11.1 — quiet fans, steady click

### Desktop

- **Playing a song stops cooking weaker Windows laptops.** On the slowest machine we test on — a QHD+ Dell running Intel HD 4600 graphics — playback ate 64% of the GPU, fans first, patience second, all for a screen where only a thin line moves. It's 8-10% now, and a paused SingZ costs exactly 0.0%. The playhead, the lit-up waveforms and the pitch view repaint only when a real pixel changes, and the transport bar on Windows trades its glass blur for a solid coat of the exact same color. You won't spot the difference; your GPU will.
- **The lyric countdown calmed down on Windows.** The "17 s" before a verse used to pulse sixty times a second, which is a lot of cardio for a number. It still ticks; it just breathes normally now. And a paused song no longer counts anything down — paused means paused.
- **The metronome survives the drummer taking a break.** Songs with a true drum void — Turn The Page's sax bridge, the intro of Going To The Run — used to coast slightly off the music through the silence. The beat grid now bridges those stretches on the song's own pulse, so Turn The Page's famous late re-entry lands exactly where Seger put it.
